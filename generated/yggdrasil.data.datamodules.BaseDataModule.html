BaseDataModule#

class yggdrasil.data.datamodules.BaseDataModule#

Base class for data modules. See the LightningDataModule for the workflow of the data module. The base data module dictates the interface to tie the the lightning data module with the TensorDataClass fromat specified by Yggdrasil.

Ovrride the following methods:

  1. prepare_data() to prepare the data for the data module.

  2. setup() to set up the data module for the specified stage.

  3. build_batch_preprocessor() to build the batch preprocessor for the data module.

  4. query_data() to query the data using the provided data extractor.

  5. run_feature_identification() to run feature identification.

  6. train_dataloader() to get the training data loader.

  7. val_dataloader() to get the validation data loader.

  8. test_dataloader() to get the test data loader.
